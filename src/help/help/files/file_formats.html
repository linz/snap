File formats

SNAP and its related programs use a number of different file formats as shown below.

Format Description
Command file syntax The syntax of commands used in command and configuration files.
Coordinate system file format Defines coordinate systems, reference frames, and ellipsoids (coordsys.def).
CSV format definition files Defines the columns of a delimited text (CSV) format file.
CSV format station coordinate files A delimited text (CSV) format station coordinate file.
CSV observation file format A delimited text (CSV) format observation file.
Grid file format A gridded data file used for geoid or deformation models in SNAP and concord.
LINZ deformation file format Represents national and local deformation fields, for example due to earthquakes.
SINEX observation files Stores GNSS-derived station coordinates and their covariances, in the IERS SINEX format.
SNAP observation file format The main SNAP format for observation data files.
SNAP Station coordinate file format The main SNAP format for station coordinate files.
Station offset file format Defines a time series of coordinate offsets at a station.
Station recode file Defines recoding of station codes when reading data files.
Triangulated data file format Represents deformation or velocity components at a set of triangulated points.
Vertical datum definition format Defines a vertical datum from which orthometric heights are measured.
