The set_observation_option command

set_observation_option option selection_criteria

The set_observation_option command is used to set options for observations that can modify how they are used in the adjustment. By default the option applies for all observations in the adjustment, but it can be restricted to a selection of observations by specifying selection criteria. The selection can be based on observation type, data file, observation date, and on station classifications. These critera are defined in the same way as in the reject_observations command.

The available options are:

calculate_gx_translation

This affects the calculation of sets of GX (GNSS correlated point coordinate sets) observations. If this option is specified then a translation will be calculated and applied to the observed coordinates to best fit them into the adjustment. This option has no effect on other data types.

use_distance_ratios_as_distances

This affects distance ratio (DR) observations. If this option is specified then the affected distance ratio data are treated as independent slope distance observations rather than as a set of dependent observations with a common scale factor. This has the same effect as the use_distance_ratios command, except that it can be restricted to a selection of observations rather than applying to all distance ratio data.

Both options are off by default for all observations, unless a matching set_observation_option command applies. Any option can be prefixed with no_ (eg no_calculate_gx_translation) to explicitly turn it off for observations matching the selection criteria.

The no_ prefix does not necessarily restore a default value - each set_observation_option command adds a modification that applies to observations matching its criteria. These are applied in the order the commands appear in the command file, so for any observation matched by more than one set_observation_option command (with or without no_), the last matching command in the file determines the final state - not whichever command has the more specific criteria.

Warning: If the criteria include selection based on certain data files, then the commands specifying those files as data files (via data_file commands) must be placed earlier in the SNAP command file.

Examples of setting observation options are:

set_observation_option calculate_gx_translation ref_frame=ITRF2000

This next example turns calculate_gx_translation on for all GX observations, then turns it back off just for observations from suspect_gx.dat:

set_observation_option calculate_gx_translation
set_observation_option no_calculate_gx_translation data_file=suspect_gx.dat

This last example demonstrates that the order of these commands matters. This turns calculate_gx_translation on for observations from suspect_gx.dat, then turns it off for all GX observations (including those from suspect_gx.dat) - so the option ends up off everywhere, because the second, broader command is applied after the first:

set_observation_option calculate_gx_translation data_file=suspect_gx.dat
set_observation_option no_calculate_gx_translation
