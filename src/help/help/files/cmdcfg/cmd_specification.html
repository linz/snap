The specification command

specification name confidence conf% [horizontal [habs mm] [hppm ppm] [hmax mm_abs]] [vertical [vabs mm] [vppm ppm] [vmax mm_abs]]

This command defines an accuracy specification that can be used to test the relative accuracy with which stations are positioned in an adjustment. There may be several specifications used in an adjustment (for example relating to different orders of station). Each specification is given a name which is used to refer to it in the test_specification command (which defines which stations it applies to).

At least one of "horizontal" or "vertical" must be given; both may be included in the same command. Within each, the mm, ppm, and mm_abs values are all individually optional, but at least one must be given. Including an mm_abs value defines an additional, separate absolute (network) accuracy test, which tests each station's absolute position error against a fixed tolerance, rather than the distance-dependent relative tolerance defined by the mm and ppm values.

For example:

specification order1 confidence 95% horizontal 5 mm 1 ppm

Defines a relative horizontal accuracy test only: a distance-dependent tolerance of 5mm + 1ppm of the distance between stations.

specification order2 confidence 95% horizontal 5 mm 1 ppm vertical 10 mm 2 ppm

Defines relative horizontal and vertical accuracy tests together.

specification network_check confidence 95% horizontal 20 mm_abs

Defines an absolute (network) horizontal accuracy test only: each station's absolute position error is tested against a fixed 20mm tolerance, independent of distance to other stations.

specification combined confidence 95% horizontal 5 mm 1 ppm 20 mm_abs vertical 10 mm 2 ppm 15 mm_abs

Defines relative and absolute accuracy tests for both horizontal and vertical in a single command.

The parameters of the command are:

name

The name used to refer to the specification.

conf

The percentage confidence to use for the test. Note that the confidence limits in specification tests are by default apriori confidence limits. This may be changed to use aposteriori confidence limits using the spec_test_options command. All specification tests have the same confidence limit type. The error_type specified for the other adjustment outputs does not affect the confidence limit type used for specification testing.

habs

The absolute component of the horizontal tolerance in millimetres

hppm

The distance dependent component of the horizontal tolerance in part per million.

hmax

An absolute horizontal accuracy tolerance in millimetres (given with the mm_abs unit). This defines a separate absolute (network) accuracy test rather than contributing to the relative tolerance formed from habs and hppm.

vabs

The absolute component of the vertical tolerance in millimetres.

vppm

The distance dependent component of the vertical tolerance in part per million.

vmax

An absolute vertical accuracy tolerance in millimetres (given with the mm_abs unit). This defines a separate absolute (network) accuracy test rather than contributing to the relative tolerance formed from vabs and vppm.
