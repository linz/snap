The standardised residual colours dialog

The standardised residual colours dialog is used to choose how observations are to be coloured based on standardised residuals. This dialog is accessed from the Observations | Colour coding | Residual menu item.

The residuals will be classified in equal sized groups from 0 up to a maximum residual. For example if the maximum is 3.00 and the number of groups is 6 then the residuals will be divided into groups with ranges 0.0 to 0.5, 0.5 to 1.0, ... , 2.5 to 3.0. snapplot adds another group for residuals greater than the maximum.

The items in this dialog are:

Residuals to use Select whether observations are to be coloured according to the apriori or aposteriori standardised residuals.
Maximum residual class The maximum value of the standardised residual to use for calculating classes. A negative value silently defaults to 1.0; values above 100 are capped at 100.0.
Number of classes The number of standardised residual classes (not including the class for values greater than the maximum). Valid values are 2 to 20. Entering 1 does not produce a single class — it silently falls back to 5 classes instead.
