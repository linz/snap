Exporting and printing the map

The current map view can be exported to a file, or printed, using the File menu.

File | Export Image saves the current map view to an image file, in either PNG or Windows bitmap (BMP) format.

File | Export DXF file saves the current map view to a DXF (AutoCAD Drawing Exchange Format) file.

File | Print map prints the current map view, using the standard system print dialog.
