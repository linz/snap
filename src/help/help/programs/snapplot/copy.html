Copying to the clipboard

The contents of each of the main snapplot windows can be copied to the clipboard using the Copy menu.

Copy | Map copies the current map view to the clipboard as an image.

Copy | Details copies the contents of the details window to the clipboard as text.

Copy | Stations copies the contents of the station list to the clipboard as text.

Copy | Observations copies the contents of the observation list to the clipboard as text.
