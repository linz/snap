Background graphics

Snapplot can display reference features such as coastlines and roads to provide a visual reference for stations and observations. Reference features are defined in simple text files. These are loaded either by include the files in the snap command file, or by specifying them when snapplot is started using the -b command line option.

Background files are specified in the command file with the command

plot background file_name

The format of the background file is very simple. #coordsys and #layer commands can appear anywhere in the file, and take effect for the coordinates that follow, until changed by another such command; both are optional, and independent of each other. #coordsys sets the coordinate system for subsequent coordinates (this can also be set via the plot background command's optional coordsys argument); coordinate lines are ignored until a coordinate system has been set, by either means. #layer sets the name of the layer subsequent coordinates belong to (or this can be set via the command's optional layer argument). Each coordinate line has a pen code and an x,y coordinate: pen code 0 continues the current feature, and any nonzero value starts a new one. If no layer has been set, each distinct nonzero pen code (including negative values) instead creates its own automatically named layer, e.g. pen code 2 creates a layer called "Background 2". #coordsys nzmg
