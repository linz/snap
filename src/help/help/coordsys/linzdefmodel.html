LINZ deformation model

The NZGD2000 datum is defined as a semi-dynamic datum, which means that NZGD2000 spatial coordinates are defined at a specific epoch (currently 2000.0 - 1 January 2000), and a deformation model is used to calculate the equivalent coordinates at other times. The New Zealand deformation model will typically include both national long-term and regional shorter-term deformation trends.

The large-scale deformation reflects plate-tectonics - the relative movement of the Pacific and Australasian tectonic plates and the distribution of this movement across New Zealand. Over a timespan of decades this is dominated by a constant velocity component (which integrates to linear displacement). Individual deformation events (earthquakes, volcanism) typically affect smaller areas and can be represented by short-term perturbations to the long-term trend.

The deformation model associated with NZGD2000 will be periodically updated, both to reflect new deformation events, and as a result of improved calculation of the long term component.

In order to represent this deformation field the LINZ deformation model can include an arbitrary number of "deformation sequences", each of which consists of one or more "deformation components". In perhaps the simplest case, the deformation at any time and place may be thought of as the sum of individual components in a sequence (see below for more complex use-cases, such as nested sequences etc.), and across all sequences.

Depending on the model version, a component's contribution beyond its own defined extent is handled in different ways. Older versions evaluate this relative to a single reference date – treating it as zero, holding it fixed, interpolating towards a neighbouring component in the same sequence, or, for a rate-of-change component, adding it with other such components to give a total velocity. Newer versions instead let a component's own value vary continuously over time, following its own profile, as illustrated above.

Newer versions may still operate identically to older versions where, by default, all of a sequence's components covering a given point – for a gridded component, point coverage is defined by the bounding box of its grid of values – are evaluated and their contributions added together. However, if a sequence is now defined as nested, only the first matching component – the first, in sequence order, whose bounding box includes the point – is used, with any other components of that sequence ignored. This avoids double-counting in cases where, for example, a detailed local patch sits inside the area of another, broader component in the same sequence. Nesting only affects how this one sequence's own components combine; every other sequence in the model is still added in as usual, regardless of whether it is nested.

Each component can define either horizontal, vertical, or three dimensional deformation/velocity fields, and can be represented as either a grid of values (on a regular grid in the coordinate system of the deformation model), or by a triangulated model. The spatial interpolation of the deformation across grid squares uses bilinear interpolation and across triangles uses linear interpolation. The east/north/up components of deformation are interpolated independently.
